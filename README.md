# POW-WOW! ❄️

Snöläget på svenska och norska skidorter – nysnö, snödjup, vind och temperatur.

**Appen:** https://davidgrehn-ui.github.io/POW-WOW/

Källor: SMHI Öppna data, YR / MET Norway (Locationforecast) och MET Norge Frost (mätdata för Trysil och Hemsedal).
`data.json` uppdateras automatiskt fyra gånger per dygn. Prognoserna hämtas dessutom direkt i webbläsaren om datan är äldre än tre timmar.
